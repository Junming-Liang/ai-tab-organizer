# 测试说明

## 自动检查

`npm run check` 检查 JS 语法、MV3 manifest 权限清单、没有内容脚本/固定 host 权限/外部消息入口，以及页面不使用远程脚本和内联事件处理。

`npm test` 使用 Node 内置测试框架，无运行时依赖，覆盖：

- URL 最小化，固定/分组/隐身/特殊协议/排除域名过滤；
- 元数据及数量边界，API 地址与显式同意校验；
- 模型未知 ID、重复 ID、格式错误、单标签组拒绝；
- 离线规则和 API 请求结构、禁用重定向/Cookie、响应大小和错误脱敏；
- 应用前保存撤销、过期/导航变更检测、已有组保护；
- 部分失败、保存组 ID 失败后的恢复、关闭/手动重新分组后的保守撤销。

`npm run build` 复制无打包运行时依赖的扩展并创建 ZIP / SHA-256。

## 真实 Chromium 冒烟

`scripts/browser-smoke.mjs` 启动临时浏览器资料，加载实际扩展。所有测试网页由 Playwright 合成，不访问用户的网站、不使用真实 API Key。验证加载、离线预览、真实原生分组、撤销、固定标签保护、导航后过期预览拒绝和设置保存。截图保存到忽略的 `artifacts/`，不包含用户数据。

需要可用的 Playwright 与 Chromium。脚本默认使用 Playwright Chromium，也可设置 `CHROMIUM_PATH`。

## 发布前手工验收清单

- 用开发者模式加载，检查服务工作线程控制台没有异常。
- 在不同窗口打开合成页面，验证整理只影响目标窗口。
- 点击预览后关闭面板、重新打开，确认可看到结果且无重复扣费请求。
- 预览后导航、关闭、固定、移动标签，再应用，应安全拒绝或保留恢复记录。
- 预先建立有名称/颜色/折叠状态的组，确认应用和撤销不拆散它。
- 模拟网络超时、401、429、无效 JSON、未知 ID；标签保持不变。
- 开启自动模式，新建标签并等待调度；撤销后自动模式关闭。
- 重启浏览器后 API Key 清除；旧版持久凭据在新版本启动时清除，即使伪造 rememberKey=true 也不能写入本地持久存储。
- 在自己的测试账户中验证真实服务模型、费用和 JSON 模式支持。

真实付费 API 调用、真实用户数据、平台外的 Chrome/Edge 兼容性和商店审核需单独验收，不能由合成测试替代。

### Companion 模拟覆盖

使用临时 RSA 签名密钥、内存凭据存储、HTTP/SSE fixture 与临时文件夹；所有密钥均为测试进程即时生成，不读取用户数据。

- PKCE/state/nonce、重放/重复参数、拒绝登录、wrong client/sub/issuer/audience/signature/expiry、可选 token hash。
- 缺 plan scope 拒绝、未完成注册保留 issued ID、账户分离、刷新轮换先保存再使用、永久/临时刷新错误区别、注销撤销未确认。

- 账户绑定改变在联网前拒绝、标题/域名字段白名单、Responses 参数、模型目录、最终拒绝/晚到错误/断流/缺正文、未知/重复标签 ID。
