AI TAB ORGANIZER / SETTINGS

整理方式，由你决定。

默认不联网。连接 AI 时，只发送标签标题和域名，
不读取网页正文、URL 路径、查询参数或浏览历史。

01 / 分类引擎

支持 Chat Completions + JSON 模式。远程地址必须是 HTTPS；本机服务可用 localhost 或 127.0.0.1。

默认只保留到浏览器关闭，不同步到云端。

本地规则按标题关键词和域名分组，不是 AI 推理，不产生 API 费用。保存本地模式会清除已有 API Key；切回 AI 时需重新填写。

02 / 分类偏好

例如 example.com 也会排除 mail.example.com。最多整理当前窗口前 100 个符合条件的标签。

默认关闭。已有分组不会重新整理；每次只保留最近一次撤销，撤销会同时暂停自动整理。

03 / 关于本机 Codex 额度

本版不会启动 Codex、不创建 Codex 会话，也不读取 Codex 账号、凭据或会话文件。

独立的 Sign in with ChatGPT 授权与 Responses 接口是后续方向，尚未实现。API Key 使用服务商 API 计费，不能代替 ChatGPT 订阅额度。

  • 不采集遥测，无广告，没有项目服务器。
  • 隐身模式不启用；固定标签和已有分组不会被整理。
  • 预览和撤销记录只保存在当前浏览器会话中，重启后清除。
  • 只在保存 API 设置时申请对应站点访问权限，可在 Chrome 扩展设置中撤销。
