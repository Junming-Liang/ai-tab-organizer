03 / 独立连接，不借用 Codex

本版不会启动 Codex、不创建 Codex 会话，也不读取 Codex 账号、凭据或会话文件。

ChatGPT 模式使用单独安装、单独登录的 SIWC companion，不启动 Codex，不读取或复用 Codex 凭据。扩展不监听本机 HTTP 服务。API 模式使用服务商 API 计费，与 ChatGPT 模式分开。

  • 不采集遥测，无广告，没有项目服务器。
  • 隐身模式不启用；固定标签和已有分组不会被整理。
  • 预览和撤销记录只保存在当前浏览器会话中，重启后清除。
  • 只在保存 API 设置时申请对应站点权限；仅在主动连接或保存 ChatGPT 模式时申请本机通信权限。可在 Chrome 扩展设置中撤销。
